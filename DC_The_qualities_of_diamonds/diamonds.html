Diamonds quality

Introduction

The aim of this analysis is to explore the qualities of diamonds and their association with price using the ggplot2::diamonds dataset.

Recall that:

  • the best cut is Ideal and the worst is Fair;
  • the best color is D and the worst is J;
  • the best clarity is IF and the worst is I1.
library(tidyverse)
library(modelr)
library(knitr)

The raw averages alone do not account for differences in diamond size.

Challenge 2: How can a model explain the apparent paradox?

CHALLENGE: “Using models, find an explanation and solve the apparent paradox.”

Lower-quality categories often contain larger diamonds. Since carat is strongly associated with price, this difference can explain the misleading raw averages.

ggplot(diamonds_data, aes(log(Carat), log(Price))) +
  geom_point(alpha = 0.08, size = 0.7) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(
    title = "Diamond price increases with carat",
    x = "Log carat",
    y = "Log price"
  ) +
  theme_minimal()

The relationship is approximately linear on logarithmic scales. We therefore model log price as a function of log carat and use the residuals to remove the effect of size.

carat_model <- lm(log(Price) ~ log(Carat), data = diamonds_data)
summary(carat_model)

Finally, we display the residual results using the same quality order as before.

residual_prices <- bind_rows(
  residuals_by_cut |> transmute(Quality = as.character(Cut), MeanResidual, Variable = "Cut"),
  residuals_by_color |> transmute(Quality = as.character(Color), MeanResidual, Variable = "Color"),
  residuals_by_clarity |> transmute(Quality = as.character(Clarity), MeanResidual, Variable = "Clarity")
) |>
  mutate(
    Variable = factor(Variable, levels = c("Cut", "Color", "Clarity")),
    Quality = factor(Quality, levels = levels(quality_prices$Quality))
  )

ggplot(residual_prices, aes(Quality, MeanResidual)) +
  geom_col() +
  facet_wrap(~ Variable, scales = "free_x") +
  labs(
    title = "Mean price residual by quality category",
    subtitle = "The effect of carat has been removed",
    x = "Quality category",
    y = "Mean price residual"
  ) +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))

After accounting for carat, better-quality diamonds generally have higher residual prices. The apparent paradox is explained by the different carat distributions: lower-quality groups often contain larger and therefore more expensive diamonds.

Conclusions

The raw mean prices suggest that lower-quality diamonds are more expensive, but these comparisons include diamonds of different sizes. The model removes the strong effect of carat from log price. The residual analysis then shows that better cut, color and clarity are generally associated with higher prices when diamond size is taken into account.
